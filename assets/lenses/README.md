Lens badge image names:

- `gm.png` for Sony GM lenses
- `g.png` for Sony G lenses
- `tamron.png` for Tamron lenses
- `sigma.png` for Sigma lenses

Sony lenses without a G or GM mark do not use a badge image.

If a badge image has a black or white background, the bot treats near-black or
near-white pixels connected to the image edge as transparent when rendering it.
